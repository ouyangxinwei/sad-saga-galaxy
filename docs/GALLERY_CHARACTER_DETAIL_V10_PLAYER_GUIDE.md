# Gallery Character Detail V1.0 — Player Guide

## View a hero's attributes

1. Open the **Gallery** from the Home menu.
2. Select the **Heroes** tab.
3. Tap a hero card that you have already obtained.
4. Review the character's level, power, maximum HP/MP, attributes, equipment, active skills, and class passive.
5. Close the detail dialog to return to the Gallery.

## Locked heroes

Heroes that have not yet been obtained remain locked. Tapping a locked card does not open character details.

## Gallery behavior

The current Gallery tab, filter, collection progress, copy count, and shard information are preserved. Enemy Gallery behavior is unchanged.

## HP and MP note

The detail view shows maximum HP and MP. Current HP/MP during a battle are shown in the battle interface.
