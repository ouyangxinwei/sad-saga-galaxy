# 绝境暴击与危机闪避系统 V1.0

## 玩法规则
- 绝境暴击：己方角色当前 HP 严格低于最大 HP 的 20% 时，普通攻击及主动攻击技能可触发，最终伤害乘以 3。
- 危机闪避：己方角色当前 HP 严格低于最大 HP 的 10% 时，受到敌方直接攻击可触发，成功后该次伤害为 0。
- HP 恰好处于 20% 或 10% 时不触发；HP 为 0 或角色已死亡时不触发。
- 暴击按一次攻击技能动作判定。多段技能及群体技能整次只进行一次暴击判定。
- 闪避按每次敌方直接命中分别判定；群体攻击的每个目标独立判定。
- 第一版不对中毒、燃烧等持续伤害或非攻击场景伤害执行闪避。

## 角色概率
- 基准概率为 20%，最终范围为 10%～30%。
- 对基础 20 名角色，分别以 HP、ATK、DEF、SPD、MP 与全体初始平均值的比例计算能力指数。
- 能力指数越高，基准概率越低；能力指数越低，基准概率越高。
- 暴击与闪避分别加入 ±2 个百分点的稳定伪随机调整。
- 调整值由角色 ID 和能力类型派生，同一角色刷新、重新进入战斗、升级、突破或更换装备后均保持不变；新角色加入不会改变既有角色概率。
- 合成生成的自定义卡按其定义中的初始基础属性参与计算。

## 实现与兼容
- 原有普通暴击率、暴击伤害、装备 onCritical 触发逻辑继续保留。
- 绝境暴击是独立的三倍伤害乘数；触发时也会触发装备 onCritical 事件。
- 概率以角色 ID 稳定计算，不向 V20 存档写入新字段，不改变现有存档结构。
- 角色详情显示两项精确概率；战斗日志显示绝境暴击 ×3 和危机闪避。
- 中、日、英三种语言均有对应文案。
