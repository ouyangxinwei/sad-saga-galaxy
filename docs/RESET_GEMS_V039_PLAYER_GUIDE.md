# V0.39 Player Guide — Reset Game

1. Open **Settings**.
2. Select **Reset Game**.
3. Confirm the reset.
4. The game starts over with **9,999 summon gems** every time.
5. All other game data returns to the existing initial defaults.

The 9,999 gems are only applied by the in-game reset action. The V13 one-time test-support grant is not granted again when resetting.

If local save storage fails, the reset is not applied and the existing game data remains in place.
