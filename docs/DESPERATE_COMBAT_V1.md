# 绝境暴击与危机闪避系统 V1.1

## 玩法规则
- 绝境暴击：己方角色当前 HP 严格低于最大 HP 的 20% 时，普通攻击及主动攻击技能可触发，最终伤害乘以 3。
- 危机闪避：己方角色当前 HP 严格低于最大 HP 的 10% 时，受到敌方直接攻击可触发，成功后该次伤害为 0。
- HP 恰好处于 20% 或 10% 时不触发；HP 为 0 或角色已死亡时不触发。
- 普通攻击每次攻击独立判定；主动攻击技能每次技能动作只判定一次。
- 多段技能与群体技能整次只进行一次暴击判定；成功后该次技能所有直接攻击伤害均乘以 3。
- 闪避按敌方每次直接命中分别判定；群体攻击的每个目标独立判定，多段敌方攻击的每一段独立判定。
- 第一版不对中毒、燃烧等持续伤害或非攻击场景伤害执行闪避。

## 角色概率
- 暴击率与闪避率分别计算，基准概率均为 20%，最终范围为 10%～30%。
- 对基础 20 名角色，分别以 HP、ATK、DEF、SPD、MP 与全体初始平均值的比例计算能力指数；先对各属性归一化，再取五项比例的算术平均。
- 基准概率按 `clamp(0.20 - (能力指数 - 1) × 0.20, 0.10, 0.30)` 计算。
- 能力指数越高，基准概率越低；能力指数越低，基准概率越高。
- 暴击与闪避分别加入 ±2 个百分点的稳定伪随机调整，调整后再次限制在 10%～30%。
- 调整值由角色 ID 和能力类型派生，同一角色刷新、重新进入战斗、升级、突破或更换装备后均保持不变；新角色加入不会改变既有角色概率。
- 合成生成的自定义卡按其定义中的初始基础属性参与计算。

## 实现与兼容
- 原有普通暴击率、暴击伤害、装备 onCritical 触发逻辑继续保留。
- 绝境暴击是独立的三倍最终伤害乘数；触发时也会触发装备 onCritical 事件。
- 概率以角色 ID 稳定计算，不向 V20 存档写入新字段，不改变现有存档结构。
- 角色详情显示两项精确概率；战斗日志显示绝境暴击 ×3 和危机闪避。
- 中、日、英三种语言均有对应文案。

## 回归测试
运行 `npm run test:equipment`，其中包含：
- 20 名角色概率范围、固定性、±2 个百分点调整范围与能力强弱方向。
- 暴击和闪避的 HP 阈值边界、死亡角色排除及独立概率判定。
- 多段主动技能只进行一次暴击抽取，触发后每一段攻击均造成三倍伤害。
- 敌方直接攻击先进行闪避判定，成功后不产生伤害事件。
