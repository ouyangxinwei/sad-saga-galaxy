# 阵型系统 V1.0

## 已确认的系统规则
- 队伍固定 5 人；阵型效果只作用于我方。
- 玩家可以为每种阵型独立安排五名当前上阵角色。
- 战斗外可以切换阵型；战斗中不允许切换。
- V1.0 提供八种阵型：五芒星阵、四方核心阵、尖锋突击阵、菱形守护阵、一字长蛇阵、十字协同阵、错位游击阵、五环均衡阵。
- 第一版不启用阵型熟练度，保留后续扩展空间。
- 默认阵型为五环均衡阵。

## Phase 1 实现范围
- `src/lib/formationSystem.js` 定义阵型、五个位置坐标、位置职责及结构化效果元数据。
- 阵型配置结构包含 `schemaVersion`、`activeFormationId` 和 `assignmentsByFormation`。
- 每种阵型分别保存五个位置的角色 ID；角色换位只修改阵型分配，不修改当前队伍名单。
- 配置规范化会清理未知阵型、重复角色、非当前队伍角色和不完整数据。
- 旧 V20 存档缺少阵型字段时，自动初始化为五环均衡阵，并以当前队伍填充位置。
- GameContext 提供 `setActiveFormation` 与 `setFormationPosition` 操作接口。
- 本阶段仅保存阵型数据和配置，不将效果应用于战斗属性、伤害、暴击、闪避或行动顺序；不修改现有编队页面。

## 八种阵型效果元数据
- 五芒星阵：核心 ATK +30%、绝境暴击概率 +5 个百分点；其他四人 HP/ATK/DEF/SPD/MP 各 -10%。
- 四方核心阵：中央角色 MP +25%、技能伤害 +10%、我方行动顺序最后；四角 DEF +5%。
- 尖锋突击阵：前锋 ATK +25%、SPD +15%；两翼暴击率 +5 个百分点；后排 DEF -10%。
- 菱形守护阵：前锋 DEF +25%、HP +20%；后卫闪避率 +10 个百分点；全队直接伤害减免 5%。
- 一字长蛇阵：全队 SPD +10%；位置顺序作为我方行动排序元数据，连续行动后续角色暴击率 +5 个百分点。
- 十字协同阵：中央 MP +25%；四周 MP 消耗 -10%；全队技能效果 +5%。
- 错位游击阵：全队闪避率 +5 个百分点；高速角色额外闪避率 +5 个百分点；全队 ATK -5%。
- 五环均衡阵：全队 HP/DEF +5%、MP +10%、暴击率/闪避率各 +3 个百分点。

## Phase 1 边界
- 不创建或修改 UI。
- 不将阵型效果接入战斗计算。
- 不增加敌方阵型、阵型克制或熟练度。
- 不改变 V20 存档版本、角色成长数据或原有队伍预设。
- 不执行完整回归测试；仅进行阵型模块针对性验证及生产构建/部署检查。
