# Per-release record template

Copy this file to `VNNN_SHORT_TITLE.md` for each formal release.

Include:
- App version and release date
- Scope and user-visible changes
- Compatibility/save-schema impact
- Test commands and results
- Git commit SHA
- GitHub Actions run URL and build/deploy job results
- GitHub Pages URL, only after successful deployment
- Manual checks still pending (especially real-device PWA checks)

Never fill commit, workflow, or deployment fields with estimates or placeholders presented as verified facts.
