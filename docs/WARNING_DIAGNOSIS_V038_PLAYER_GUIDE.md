# V0.38 Player Guide — Warning Diagnosis

1. Open **Settings → Debug Console**.
2. Select **Warning Diagnosis**.
3. Select **Run Warning Simulation**.
4. Review the four scenario results and any captured warnings.
5. Review **Real gameplay warning records** to group warnings already stored by the normal Debug Logger.
6. Export the latest report as JSON when sharing a diagnostic report is useful.
7. Select an item in Diagnosis history to reopen an earlier report.

The simulation uses temporary battle data. It does not consume tickets, stamina, gold, gems, or other resources and does not overwrite the game save.

A clean result means the covered scenarios completed without captured WARN/ERROR records. It does not guarantee that every possible real gameplay path is warning-free.
